繳交標題：清大 112034058 工工大四 鄭宇辰 啟程前：用 AGENTS.md 延伸旅行準備指南

一、專案簡介

我選擇做「啟程前」旅行準備指南，整理行李、交通、行前檢查與住宿入住的準備方法。每篇都有步驟、可勾選清單、常見漏項與需要另外確認的資訊。網站可以搜尋、依分類篩選，也能在同一瀏覽器保存每篇的勾選進度。

原有 GitHub Repository：https://github.com/daniel095501/-

本文件建立時尚未成功上傳；提交作業前須完成發布，再填入實際可開啟的網頁網址。

三、AGENTS.md 的設計

我把專案目的、繁體中文文案、色彩和版面、檔案結構、內容格式、命名方式、互動規則與檢查流程寫進 AGENTS.md。規則要求每篇都包含「這篇解決什麼、準備步驟、出發前勾一遍、常見漏項、需要另外確認」，也明確禁止編造票價、班次或目的地規定。

規則文件位於 travel-guide/AGENTS.md。網站的「專案規則」連結也能開啟這份文件。

四、之後如何讓 AI 繼續新增

每篇內容放在 content/guides/ 的 JSON 檔，共用版型、CSS 與 JavaScript 另外管理。之後只要請 AI 先讀 AGENTS.md，參考既有 JSON 新增一篇，再執行建置與檢查，首頁、導覽和相關指南就會一起更新，不需要每次重新描述整個網站的外觀。

這次先完成行李、交通與行前三篇，再依相同規則新增住宿入住篇。新增內容當下，比對七個共用檔案皆未改變。後續瀏覽器檢查發現手機裝飾圖溢出，再另外修正共用樣式，沒有把這項修正混寫成「完全沒有改程式」。

五、理解與驗證

我理解這次和單純做一個網頁的差別，在於把之後怎麼新增、怎麼修改以及怎麼確認正確，也先寫清楚。AGENTS.md 是給 AI 的維護規則，JSON 是每篇內容，版型負責把內容整理成一致的頁面；三者要互相對應，不能只有一份看起來很完整卻沒有實際使用的規則。

AI 協助執行的本機檢查包括資料格式、頁面結構、106 個站內連結與資產引用，以及 12 項瀏覽器功能檢查。手機 390px 與 320px 的五個頁面均無水平溢出；搜尋、勾選保存、逐篇重設、沒有 JavaScript 與儲存失敗的情況都有檢查。這些是本機結果，公開部署仍需另外驗證。
